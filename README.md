# 🎮 Interactive Hangman Game

An interactive, responsive, and modern **Hangman Game** built from scratch using **Vanilla JavaScript, HTML5, and CSS3**. Featuring a clean glassmorphism interface, dynamic difficulty scaling, and automated DOM rendering without external libraries or frameworks.

- 💻 **GitHub Repository:** [https://github.com/msknh3x/hangman-game](https://github.com/msknh3x/hangman-game)

---

## Features

-  **3-Tier Adaptive Difficulty:**
  - **Easy:** 8 Lives — Common & shorter words.
  - **Medium:** 6 Lives — Moderate length vocabulary.
  - **Hard:** 4 Lives — Advanced terminology & strict chances.
-  **Dynamic DOM Keyboard:** All 26 alphabet buttons (`A-Z`) and word blanks (`_ _ _`) are generated and managed dynamically via JavaScript.
-  **Modern & Clean Glassmorphic UI:** Sleek frosted glass cards (`backdrop-filter`), smooth hover transitions, and subtle lighting effects.
-  **Pure Vanilla JavaScript Logic:** Real-time state management using ES6 array methods (`.includes()`, `.map()`, `.every()`, `.split()`).
-  **Instant Game Lifecycle Reset:** One-click "Play Again" button and instant difficulty switching with zero page reloads.
-  **Fully Mobile Responsive:** Optimized grid and flex layouts that adjust seamlessly across mobile phones, tablets, and desktop screens.
